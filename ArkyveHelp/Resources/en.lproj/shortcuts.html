Using Arkyve from Shortcuts

The Shortcuts app is a great way to automate various tasks on your Mac using functionality provided by macOS and the applications you have installed.

Arkyve provides a number of actions that can be used in Shortcuts, including:

  • Creating an empty archive
  • Adding files to an existing archive
  • Extracting some/all items from an archive
  • Listing the contents of an archive
  • Converting an archive from one format to another

For more information, please see the documentation for the Shortcuts app.
