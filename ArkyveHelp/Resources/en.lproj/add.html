Adding files and folders to an archive

There are several ways to add files and folders to an archive:

1. Click the Add button on the toolbar (which looks like a +)

2. Select "Add Files/Folders" from the Items menu

After choosing either of those options, a file browser will be shown which you can use to select one or more files and folders, which will then be prepared for adding to the archive.

 

You can also drag files/folders onto an archive window, e.g. from a Finder window.

 

Important Note:

The archive is not immediately saved to disk, you must manually save your changes or they will be lost
