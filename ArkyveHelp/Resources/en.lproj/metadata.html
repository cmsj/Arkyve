Changing dates and permissions in an archive

Every item in an archive has various pieces of metadata attached to it - typically dates and POSIX permissions. Arkyve allows you to modify some of these if required:

  1. Date Modified - when the file's contents were last changed
  2. Date Accessed - when the file was last opened
  3. Date Created - when the file was created
  4. Date Changed - when the file's metadata was last changed
  5. Permissions - normal POSIX file permissions
