Renaming items in an archive

There are several ways to rename a file or folder in an archive. Start by clicking on the item you want to rename, then

  1. Right click on it and choose "Rename"
  2. Select "Rename" from the Items menu
  3. Click on the Rename button on the toolbar:

 

Once the renaming action has been initiated, the name of the archive will be editable (as shown below). Once you have entered the new name you want, press Return/Enter to confirm.

Arkyve will then check the name you have entered and display an error if there is a problem (for example, you cannot have two files with the same name)

 

Important Note:

The archive is not immediately saved to disk, you must manually save your changes or they will be lost
